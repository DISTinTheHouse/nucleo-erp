Flujo del CRM

Cotizada y Ganada no se guardan: se calculan de las cotizaciones ligadas (con cotización = Cotizada; alguna autorizada = Ganada). Por eso el flujo cotización → mesa de control → pedido no se toca.

Reglas: cotizar o ligar exige cliente y vendedor activo, y no se puede en Ganada ni Perdida (para vender más, abre otra). Una cotización autorizada no se quita de la oportunidad. Una Ganada no se puede marcar Perdida. Solo el admin de empresa transfiere oportunidades a otro vendedor. El vendedor ve las suyas; el admin, toda la empresa.

API (/api/v1/ventas/): oportunidades/ (filtro ?estado=), embudo/, {id}/cotizar/, {id}/cotizaciones/ (GET/POST, DELETE {id}/cotizaciones/{cot}/), {id}/transferir/, oportunidad-seguimientos/ (agenda de pendientes, {id}/completar/). Los recordatorios no avisan solos: el frontend consulta los pendientes.
